# Smart Clinic Queue Management System — Frontend

A web-based frontend application designed to help patients access clinic information and queue details through a simple and user-friendly interface.

##  About the Project

The Smart Clinic Queue Management System aims to make clinic visits more convenient by helping patients check queue information and estimated waiting times before visiting a clinic.

The application provides separate dashboards for patients and doctors to support their respective activities.

##  Features

- Patient Registration and Login
- Patient Dashboard
- Doctor Dashboard
- Clinic Information
- Queue Management Interface
- Estimated Waiting Time Interface
- User-Friendly Interface
- Responsive Web Design

*Note: Features depend on the functionality implemented and connected in the application.*

##  Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
